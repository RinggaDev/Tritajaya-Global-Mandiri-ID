# Tritajaya Global Mandiri — VRF/HVAC Company Profile

This is the Vite + React + TypeScript application for the Tritajaya Global Mandiri website.

See the [root README](../README.md) for the complete project documentation: pages, content files, survey email setup, deployment, and design references.

## Quick start

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm run lint
npm run preview
```

Site copy lives in `src/content/*.json`; case-study photos live in `public/`. The contact form requires the three Resend environment variables documented in `.env.example` and the root README.
